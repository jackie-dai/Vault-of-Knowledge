## Reading a Z-table
![[Pasted image 20260923131858.png]]
Z_0.025 means 0.025 + 0.025 = 0.05 summed from both sides. 1-a = 1-0.05 = 95% confidence interval. 

1-0.025 = 0.975 so we can look at the table for the cell that matches 0.975. Adding the row 1.9 + 0.6 col, we get 1.96 for the standard deviation.
